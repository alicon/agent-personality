## Development observations, not study results

The adapter-only engineering request used 46 generated tokens versus 135 for prompt-only in this one deterministic example. It also asserted “the import must have lost them,” despite the request saying the cause was unknown. The prompt-only reply added an unsupported claim that validation was blocked. Shorter text alone did not solve factual restraint.

In the wholly hypothetical probability case, all four replies rejected the user's 99% claim and gave roughly 9%; the exact probability from the invented inputs is 8.264%. The hybrid reply then asked whether to “keep the 99% figure as a rough guide.” That is a substantive failure to preserve the correction. The adapter-only reply did not make that offer, but one example is insufficient to compare reliability.

These observations motivate training contrasts that pair friendly, brief presentation with uncertainty and sustained disagreement. None of the fifty fixtures has been calibrated to Abel. There was no blinded human scoring, correction-effort study, repeated seed or long conversation. Do not claim that learned disposition outperforms an optimized prompt baseline from this run.
