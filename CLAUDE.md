# Agent map

Read README.md, then the document owning the task. Research lives in docs/research.md; dated observations in docs/local-observations.md; experiment design in docs/experiment.md; candidate architecture in docs/architecture.md.

- Follow Abel's current request and the shared human-communication skill. Keep the shared voice pointer central rather than copying its rules into this repository.
- Keep demonstrated findings, local observations, hypotheses, proposed designs, and executed experiments distinct.
- Do not change live disposition, skills, model catalogs, or configuration as a side effect of research.
- Propose changes to core disposition for Abel to review. Factual memory and task lessons do not automatically amend it.
- Use wholly invented examples for probes. Do not copy private work transcripts or patient information into this repository or training data.
- Record the actual instruction assembly boundary available. A file hash, session summary, or the model's recollection is not a complete outbound request trace.
- Preserve warranted disagreement and justified revisions. Consistency or shortness alone is not success.
- Update the smallest owning document when a finding or experiment status changes.
- Run python3 -m unittest discover -s tests -v before handing off changes. State separately whether model evaluations ran.

AGENTS.md is a local, ignored symlink to this file.
